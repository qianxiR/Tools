# Qwen3-VL 目标检测 · 通用训练 / 推理 / 评估流程

本项目以 Qwen3-VL（语言侧 LoRA + 冻结 SigLIP2 Base 特征注入）做目标检测：模型自回归输出 `<obj>` 包裹的 JSON `bbox_2d`，坐标为 0-1000 归一化裸整数 `[x1,y1,x2,y2]`（沿用基座原生词表，不再使用 location token）。
本文档描述从原始数据到 **训练 → 推理 → 评估 → 可视化** 的完整通用流程，适用于任意单类 / 多类检测数据集。
内置 **VOC**、**YOLO** 两种输入格式转换器；切换数据集只需改「数据路径 + prompt 文件 + 类别表」。

> 当前以 **管网缺陷 · 数据_筛选3000**（YOLO，12 类）作为运行示例；括号内标注切换其它数据集的方法。


依赖 `llamafactory` 环境（transformers **4.57.6** + peft 0.18.1 + torch 2.11.0+cu128）。

### 2. 生成训练数据（若 JSONL 尚未产出）

训练读取的是 Qwen3-VL 对话 JSONL，需先从原始标注转换。当前默认数据集为「管网缺陷·数据_筛选3000」（YOLO 格式，12 类）：

## 1. 数据集路径与格式

支持两种原始标注格式，任选其一。`<DATASET_ROOT>` 为数据集根目录。

### 1.1 VOC 格式（绝对像素 xyxy）

```text
<DATASET_ROOT>
├── images/<id>.<ext>          # .tif / .jpg / .png ...
└── Annotations/<id>.xml       # Pascal VOC，坐标为原图绝对像素 xyxy
```

### 1.2 YOLO 格式（归一化 cxcywh）

```text
<DATASET_ROOT>
├── images/<id>.<ext>
├── labels/<id>.txt            # 每行: class_id x_center y_center width height（均 0-1 归一化）
├── labels/classes.txt         # 类别代码，行序即 class_id（0 基）
└── split/{train,val,test}.txt # 每行 images/<id>.<ext>
```

**当前示例**：`DATASET_ROOT = F:\数据集\GW\数据_筛选3000`，YOLO 格式，12 类，3000 图，已预切分 train 2100 / val 300 / test 600。

## 2. 格式转换（→ Qwen3-VL JSONL）

统一转为 Qwen3-VL 对话 JSONL，坐标归一化到 **0-1000**（x 以原图宽、y 以原图高为基准，与推理反归一化严格互逆）。

### 2.1 YOLO 数据

```powershell
python scripts/convert_yolo_to_qwenvl.py
```

输出到 `<DATASET_ROOT>`：

- `pipe_qwenvl.jsonl`（全量）
- `pipe_qwenvl_train.jsonl` / `pipe_qwenvl_val.jsonl` / `pipe_qwenvl_test.jsonl`

类别映射（代码 → 中文）取自 `data/pipe_defect_3000_prompt_train_en.json` 与 `data/pipe_defect_3000_prompt_infer_en.json` 的共同 `label_codes`：`CR→穿入`、`JG→结垢`、`CJ→沉积` … 共 12 类。训练 prompt 与推理 prompt 使用相同标签合同和坐标协议。
切分沿用数据集自带 `split/*.txt`；转换时自动跳过退化框并打印各类框数与最长答案长度（用于核对 `MAX_LENGTH`）。

### 2.2 VOC 数据

```powershell
python scripts/convert_voc_to_qwenvl.py
```

输出 `landslide_qwenvl*.jsonl`（单类 `landslide`，按 8:1:1 固定种子随机切分）。

### 2.3 JSONL 输出格式

```json
{
  "id": "0005f4e338cfed18eac8720ed68929e6",
  "image": "F:\\数据集\\GW\\数据_筛选3000\\images\\0005f4e338cfed18eac8720ed68929e6.jpg",
  "conversations": [
    {"from": "user",      "value": "<image>\n<检测 prompt>"},
    {"from": "assistant", "value": "<obj>[{\"bbox_2d\":[547,749,1000,1000],\"label\":\"CJ\"}]</obj>"}
  ]
}
```

- `bbox_2d` 为 **0-1000 归一化裸整数坐标**（非像素）；JSONL 里直接存裸整数，训练时用基座原生数字 token 训练，不引入 location token。
- assistant 输出以 `<obj>...</obj>` 包裹 JSON 数组；多目标为数组，无目标为 `<obj>[]</obj>`。
- label 用类别代码（`CJ`/`CR`/`SG` …），非中文名。

> 训练与推理 prompt 已分离：转换器和训练默认读取 `data/pipe_defect_3000_prompt_train_en.json`；推理和评估默认读取 `data/pipe_defect_3000_prompt_infer_en.json`。两份文件共享 `label_codes`、`<obj>...</obj>` 和 `raw_integer_0_1000` 协议，但训练版更短，推理版包含完整视觉证据规则。切换数据集时分别准备两份 prompt JSON。

## 3. 训练（LoRA + SigLIP2 Base 特征注入）

```powershell
python train_qwen3vl_lora.py
```

所有路径与开关支持**环境变量覆盖**，默认即管网缺陷数据集 + bf16：

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `MODEL_PATH` | modelscope `Qwen3-VL-4B-Instruct` | 基座 |
| `DATASET_ROOT` | `F:/数据集/GW/数据_筛选3000` | 数据根 |
| `TRAIN_JSONL` | `<root>/pipe_qwenvl_train.jsonl` | 训练集 |
| `VAL_JSONL` | `<root>/pipe_qwenvl_val.jsonl` | 验证集（仅加载，不参与评估） |
| `TRAIN_PROMPT_JSON` | `data/pipe_defect_3000_prompt_train_en.json` | 训练与 YOLO 转换使用的简洁英文 prompt；兼容回退变量 `PROMPT_JSON` |
| `INFER_PROMPT_JSON` | `data/pipe_defect_3000_prompt_infer_en.json` | 推理与评估使用的完整英文视觉判据 prompt；兼容回退变量 `PROMPT_JSON` |
| `USE_4BIT` | `0`（bf16） | `1`=QLoRA 4bit（见 §0 警告，开启即抛错） |
| `SWANLAB_PROJECT` | `qwen3vl-pipe-defect-detect` | 日志项目名 |
| `SWANLAB_MODE` | `local` | `disabled` 可关闭日志 |
| `SIGLIP_MODEL_PATH` / `NUM_TRAIN_EPOCHS` / `AUGMENT_TRAIN` | 见脚本 | 外部主干 / epoch(默认 30) / 数据增强开关 |

> 注：脚本顶部另有 `TEXT_LORA_LR`/`VISION_LORA_LR`/`EXTERNAL_ADAPTER_LR`/`WARMUP_STEPS` 等分组常量，**已废弃**（仅写入 swanlab config 展示、不进优化器）。实际生效的是 `build_optimizer` 内对所有参数组统一的 `UNIFIED_LR=1e-4` constant、`warmup_steps=0`。

**切换到滑坡数据集**示例（PowerShell）：

```powershell
$env:DATASET_ROOT = "H:/西藏遥感Agent/dataes/LandSlideDataSet"
$env:TRAIN_JSONL  = "$env:DATASET_ROOT/landslide_qwenvl_train.jsonl"
$env:VAL_JSONL    = "$env:DATASET_ROOT/landslide_qwenvl_val.jsonl"
$env:TRAIN_PROMPT_JSON = "data/pipe_defect_3000_prompt_train_en.json"
$env:INFER_PROMPT_JSON = "data/pipe_defect_3000_prompt_infer_en.json"
$env:OUTPUT_DIR   = "output/landslide_lora"
python train_qwen3vl_lora.py
```

**训练产出**（`<OUTPUT_DIR>/best_adapter/`，按训练配置还可能写出 `<OUTPUT_DIR>/checkpoint-*/` 与 `final_adapter/`，非固定结果）：

- LoRA 权重（`adapter_model.safetensors` 等；词表保持基座原生，不扩展）
- `external_feature_adapter.pt`（SigLIP2 四层多深度特征 + SimpleFPN/MultiScaleFusionDecoder + projector 权重，`format_version=8`；旧 v7/v6 权重不兼容）
- processor（tokenizer / preprocessor）

> ⚠️ **训练/推理一致性**：推理必须**同时**加载 LoRA adapter 与 `external_feature_adapter.pt`（`load_external_adapter(strict=True)`），否则 SigLIP2 特征注入在推理失效，训练/推理分布不一致。

**日志**：swanlab。`local` 模式需 `swanboard`（`pip install 'swanlab[dashboard]'`）；未安装时设 `SWANLAB_MODE=disabled` 跳过日志，不影响训练。

## 4. 推理（Gradio 单图交互）

```powershell
python inference.py --adapter output/pipe_defect_lora_siglip2_base_v8/best_adapter
```

- 默认地址 `http://127.0.0.1:7860`。
- 上传图像（`.tif` 自动转 PNG），模型使用**推理 prompt**输出 JSON bbox，画框存图并在聊天窗口给出 `norm` / `pixel` 坐标与原始输出。推理 prompt 比训练 prompt 更完整，包含视觉证据和误检抑制规则。
- 常用参数：`--port`、`--share`、`--max-new-tokens`。

输出：

1. 画框结果图：`output/infer/result_<timestamp>.png`（交互推理临时输出，非固定结果）
2. 聊天文本：`Detected <N> target(s)` + 逐框 `label / norm / px` + `raw output`

```text
Detected 1 target(s) in 4.4s (image 1920x1080).
  [0] label=CJ norm=[547,749,1000,1000] px=[1050,809,1920,1080]
```

> ✅ **已对齐**：`inference.py` 以 **bf16** 加载基座（与训练精度一致），默认从 `data/pipe_defect_3000_prompt_infer_en.json` 读取完整推理 prompt；加载 LoRA 时以 `load_external_adapter(strict=True)` 同步恢复 `external_feature_adapter.pt`（缺失即抛错，杜绝 SigLIP2 特征注入静默失效）；词表保持基座原生不扩展，不注册 location token、不 `resize_token_embeddings`；`decode_bbox(allow_legacy_numeric=True)` 直接按裸整数解析 bbox（亦兼容历史 location token 输出）。切换数据集时改 `INFER_PROMPT_JSON`（或兼容回退 `PROMPT_JSON`）与 `--adapter`；推理 prompt 的完整视觉约束不应直接写入训练 prompt。

## 5. 评估（test 集指标）

```powershell
python evaluate_detection.py `
  --adapter output/pipe_defect_lora_siglip2_base_v8/best_adapter `
  --test-jsonl F:/数据集/GW/数据_筛选3000/pipe_qwenvl_test.jsonl
```

> **当前固定结果**：`数据_筛选3000` test=600、IoU=0.5，当前 v8 `best_adapter` 的 F1=**0.4245**、P=0.4841、R=0.3780、AP50=0.1931、mAP50-95=0.0926；TP/FP/FN=457/487/752。归档位于 `output/pipe_defect_lora_siglip2_base_v8/results/`，完整 per-class 指标见 [实验记录.md](实验记录.md)。

**指标**（IoU 阈值默认 0.5，`--iou-threshold` 可调）：

```text
Precision / Recall / F1
mean matched IoU
AP50 / mAP50:95
TP / FP / FN
invalid bbox outputs
```

**输出文件**（当前归档）：

- `output/pipe_defect_lora_siglip2_base_v8/results/test_predictions.jsonl`：首行为汇总 metrics，后续每图 `gt_boxes` / `pred_boxes`（均原图像素坐标）+ `raw_output`。
- `output/pipe_defect_lora_siglip2_base_v8/results/visualizations/<id>.png`：600 张逐图可视化。
- `output/pipe_defect_lora_siglip2_base_v8/results/confusion_matrix.json` / `confusion_matrix.png`：混淆矩阵。
- `output/pipe_defect_lora_siglip2_base_v8/results/validation_metrics.jsonl`：训练期验证曲线。

## 6. 可视化

可视化在两处产出，均把 0-1000 坐标还原为原图像素后画框：

| 来源 | 命令 | 输出 | 图例 |
|---|---|---|---|
| 评估 | `evaluate_detection.py` | `output/pipe_defect_lora_siglip2_base_v8/results/visualizations/<id>.png` | 绿框 = GT，红框 = Pred |
| 推理 | `inference.py` | `output/infer/result_<ts>.png` | 红框 + label 文本 |

可选指定评估可视化目录（默认即固定结果目录，可不传）：

```powershell
python evaluate_detection.py --adapter output/pipe_defect_lora_siglip2_base_v8/best_adapter `
  --test-jsonl F:/数据集/GW/数据_筛选3000/pipe_qwenvl_test.jsonl `
  --vis-dir output/pipe_defect_lora_siglip2_base_v8/results/visualizations
```

**输出格式约定**（转换 / 训练 / 推理 / 评估全流程统一）：

```json
<obj>[{"bbox_2d":[x1,y1,x2,y2],"label":"<code>"}]</obj>
```

坐标为 0-1000 归一化裸整数 `[x1,y1,x2,y2]`（沿用基座原生词表；推理/评估解析端经 `decode_bbox(allow_legacy_numeric=True)` 解析，亦兼容历史 location token 输出）；推理与评估脚本按 `bbox_2d[i]/1000*W|H` 还原像素并画框，不使用 `<box>` / `<|box_start|>` / `<points>` 等 Qwen2-VL 包裹格式。label 用类别代码（非中文）。
