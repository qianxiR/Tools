# 实验记录

> 本文件集中记录 QwenDec 的训练与评估结果。工程架构和运行约束见 `AGENTS.md`，完整命令见 `训推.md`。
>
> 除明确标注的失败快速验证外，结果统一基于 `数据_筛选3000`（train=2100 / val=300 / test=600）和 test IoU=0.5。不同数据切分的 F1 不可直接比较。

---

## 一、当前固定基线

- **架构**：SigLIP2 Base 第 3/7/9/12 层四层多深度特征拼接 → SimpleFPN（4S/2S/1S/0.5S）+ 粗到细 MultiScaleFusionDecoder 真多尺度融合 + 16x16（256）外部前缀 token + Qwen 原生视觉塔/语言 decoder LoRA。
- **坐标**：0-1000 归一化裸整数，沿用基座原生词表，不注册 location token，不 resize。
- **训练**：LoRA(r=32, alpha=64, dropout=0.05)，统一 lr=1e-4 constant，batch=2 x accum=4，30 epoch，水平翻转增强，标准 LM CE，norm 微调关闭。
- **验证**：每 3 epoch 全量验证，当前最终训练关闭早停并跑满 30 epoch；best 由 val F1 选出（best epoch=15）。
- **adapter**：`output/pipe_defect_lora_siglip2_base_v8/best_adapter`（外部 adapter `format_version=8`，SimpleFPN 多尺度融合）。
- **测试归档**：`output/pipe_defect_lora_siglip2_base_v8/results/test_predictions.jsonl`。
- **可视化**：`output/pipe_defect_lora_siglip2_base_v8/results/visualizations/`（600 张，GT 绿框 / Pred 红框）。
- **训练配置详情**：SigLIP2 输入 256×256，patch 16×16，网格 16×16；多尺度层 (3,7,9,12)；SimpleFPN 尺度因子 (4,2,1,0.5)；projector 为 Linear(256→512)→SiLU→Linear(512→hidden_size)+LayerNorm+2D 位置编码；优化器 PagedAdamW8bit，lr=1e-4 constant，warmup=0；梯度裁剪 1.0；bf16；梯度检查点启用。

## 二、坐标方案结论

- 裸整数坐标起步 loss 约 0.6，epoch 1 val F1 约 0.30。
- 初次 location-token 实验起步 loss 约 23，epoch 1 F1 约 0.046，出现约 708 个 FP，坐标生成失效。
- 后续在 `数据_筛选500` 上进行的 location-token/LPM 快速验证，即使加入 Triplet、Gaussian 和两阶段训练，best val F1 也仅 0.0811。
- 失败实验的模型、checkpoint、专属 prompt、计划和日志已删除；推理端只保留历史输出解析兼容。
- **方法选型结论：训练链只使用裸整数与标准 LM CE，不再开展新增坐标 token 路线。**

### 3.3 瓶颈判断

- TP 框的 mean IoU=0.7847 且 invalid bbox=0，说明 JSON 协议和已发现目标的定位不是首要故障。

**v8 vs v7 消融结论**：将外部特征从「3/7/12 三层通道拼接」升级为「3/7/9/12 四层 → SimpleFPN 4S/2S/1S/0.5S 真多尺度融合」，Test F1 持平略降（0.4245 vs 0.4268），但 Precision 明显上升（+0.0497）、Recall 明显下降（-0.0414），AP50/mAP50-95 也略降。说明真空间多尺度融合未提升整体检测能力，反而使候选发现更保守——SimpleFPN 路线对当前数据规模/任务无正向收益。

## 五、后续改进优先级

1. **SigLIP2 输入分辨率提升**：先做 SigLIP2 输入 384（24x24 patch）后自适应池化回 16x16、仍注入 256 prefix 的单变量实验，用于隔离"输入分辨率"收益；若有效，再单独比较保留 24x24 网格的 576 prefix。SimpleFPN 真多尺度融合（v8）已验证无 F1 收益，分辨率提升是另一条独立变量。
2. **类别均衡与困难样本采样**：按 FS/TL/AJ/PL 的图像级出现频率做 weighted sampler，并增加包含易混类别或多目标的 hard-example 采样。不要先改 loss，先验证采样能否提升这些类的 recall（v8 的 FS R=0.1709、TL R=0.2174 仍是最差）。
3. **bbox 安全的定向增强**：在保留水平翻转的基础上，加入围绕 GT 的随机扩边裁剪、轻度亮度/对比度/锐度和噪声扰动；所有几何增强必须同步变换 bbox，并保证 Qwen ViT 与 SigLIP2 输入同图。
4. **原生词表约束解码**：保持裸整数，不改 tokenizer；可用 JSON schema/状态机限制括号、字段、label 集和 0-1000 数字范围。它主要降低格式漂移，预计对当前 invalid=0 的收益有限，因此优先级低于视觉与采样。
5. **严格单变量消融**：固定同一 2100/300/600 切分、seed、30 epoch、best-by-val-F1、test 推理参数和无 NMS 默认设置；一次只改变分辨率、采样或增强中的一个变量，并始终对比 F1=0.4245。
