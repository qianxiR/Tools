# 震后滑坡生态恢复知识图谱结构说明

## 📖 概述

本文档详细描述了"震后滑坡生态恢复知识图谱"的完整结构，包括节点类型、关系类型以及整体层级逻辑。该知识图谱构建了一个多尺度、多指标、多时相的生态恢复监测网络，用节点表达地物对象、生态指标、时空尺度，用关系串起演化逻辑与语义推理，实现从"数据"到"知识"的结构化表达。

---

## 🧩 一、节点类型（实体类）

脚本共定义了 **11 类**主要节点类型，对应知识层级如下：

| 层级 | 标签 | 典型示例 | 含义 |
|------|------|----------|------|
| ① | 本体 | 震后滑坡生态恢复 | 知识图谱的根节点，定义主题领域 |
| ② | 实体 | 滑坡、植被、土壤 | 表征具体生态要素 |
| ③ | 状态 | 发生前、恢复中、已恢复 | 表征生态系统的演化阶段 |
| ④ | 指数 | NDVI、NDWI、NBR | 遥感反映生态状况的物理量 |
| ⑤ | 指标 | 滑坡面积 | 空间定量指标 |
| ⑥ | 时间尺度 | 宏观分析、中观分析、微观分析 | 表示分析的时间粒度 |
| ⑦ | 时相 | T1_震前、T4_已恢复 | 时间片段，用于时序演化 |
| ⑧ | 空间区域 | 九寨沟滑坡区 | 具体的地理区域 |
| ⑨ | 图斑 | Sentinel-2 图斑 T33TWN 等 | 遥感像元或分块对象 |
| ⑩ | 监测场景 | 震后九寨沟滑坡生态恢复监测 | 综合描述一个监测任务 |
| ⑪ | 语义层 | 多尺度遥感监测语义 | 表示知识图谱推理语义说明 |

### 节点类型说明

- **本体节点**：作为知识图谱的顶层概念，定义整个知识领域的主题
- **实体节点**：表示具体的生态要素，如滑坡、植被、土壤等
- **状态节点**：描述生态系统的演化阶段，具有时间顺序性
- **指数节点**：遥感监测的物理量指标，用于量化生态状况
- **指标节点**：空间定量指标，如滑坡面积等
- **时间尺度节点**：定义分析的时间粒度（年/季/月）
- **时相节点**：时间片段，用于描述时序演化过程
- **空间区域节点**：具体的地理区域，如九寨沟滑坡区
- **图斑节点**：遥感数据的最小单元，如 Sentinel-2 图斑
- **监测场景节点**：综合描述一个完整的监测任务
- **语义层节点**：提供知识图谱推理的语义说明

## 🔗 二、主要关系类型与逻辑结构

知识图谱中定义了多种关系类型，用于连接不同类型的节点，形成完整的知识网络。

| 关系类型 | 含义 | 示例 |
|----------|------|------|
| `包含实体` | 本体包含多个实体 | `(本体)-[:包含实体]->(滑坡)` |
| `时间顺序` | 表示状态之间的演化顺序 | `(发生后)-[:时间顺序]->(恢复中)` |
| `监测指标` | 实体关联到遥感指数 | `(植被)-[:监测指标]->(NDVI)` |
| `包含实体` | 滑坡包含土壤和植被 | `(滑坡)-[:包含实体]->(土壤)` |
| `演化到` | 时相的时间演化 | `(T1_震前)-[:演化到]->(T2_震后)` |
| `对应状态` | 时相对应生态状态 | `(T3_恢复中)-[:对应状态]->(恢复中)` |
| `空间属性` | 实体拥有的空间特征指标 | `(滑坡)-[:空间属性]->(滑坡面积)` |
| `发生于` | 实体与地理区域关联 | `(滑坡)-[:发生于]->(九寨沟滑坡区)` |
| `影响阶段` | 指标作用于不同恢复阶段 | `(滑坡面积)-[:影响阶段]->(恢复中)` |
| `参与分析` | 指标参与不同时间尺度分析 | `(滑坡面积)-[:参与分析]->(宏观分析)` |
| `联合评估` | 指标与指数联合用于生态评估 | `(滑坡面积)-[:联合评估]->(NDVI)` |
| `语义解释` | 本体或场景对应语义说明 | `(场景)-[:语义解释]->(语义层)` |
| `监测对象` | 场景与监测对象的关联 | `(场景)-[:监测对象]->(滑坡)` |
| `监测区域` | 场景与监测区域的关联 | `(场景)-[:监测区域]->(九寨沟滑坡区)` |
| `监测尺度` | 场景与时间尺度的关联 | `(场景)-[:监测尺度]->(宏观分析)` |
| `分析指标` | 场景使用的分析指标 | `(场景)-[:分析指标]->(NDVI)` |
| `反映状态` | 场景反映的生态阶段 | `(场景)-[:反映状态]->(恢复中)` |
| `包含图斑` | 空间区域包含具体遥感图斑 | `(九寨沟滑坡区)-[:包含图斑]->(T33TWN)` |
| `观测于` | 图斑对应时间尺度 | `(T33TWN)-[:观测于]->(宏观分析)` |
| `对应状态` | 图斑对应语义恢复阶段 | `(T33TWN)-[:对应状态]->(已恢复)` |
| `观测指数` | 图斑观测的遥感指数 | `(图斑)-[:观测指数]->(NDVI)` |
| `在时间尺度观测` | 图斑在特定时间尺度下观测指数 | `(图斑)-[:在时间尺度观测]->(指数)` |

### 关系类型分类

#### 1. 层次关系
- `包含实体`：表示本体与实体、实体与子实体的包含关系
- `包含图斑`：表示空间区域与图斑的包含关系

#### 2. 时间关系
- `时间顺序`：表示状态之间的时间演化顺序
- `演化到`：表示时相之间的时间演化
- `观测于`：表示图斑与时间尺度的关联

#### 3. 监测关系
- `监测指标`：实体与遥感指数的关联
- `观测指数`：图斑与指数的观测关系
- `在时间尺度观测`：图斑在特定时间尺度下观测指数

#### 4. 语义关系
- `对应状态`：时相或图斑与生态状态的对应关系
- `语义解释`：本体或场景与语义层的关联

#### 5. 空间关系
- `空间属性`：实体与空间指标的关联
- `发生于`：实体与地理区域的关联

#### 6. 分析关系
- `影响阶段`：指标对恢复阶段的影响
- `参与分析`：指标参与不同时间尺度的分析
- `联合评估`：指标与指数的联合评估关系

#### 7. 场景关系
- `监测对象`、`监测区域`、`监测尺度`、`分析指标`、`反映状态`：监测场景的多维关联

## 🧠 三、整体层级逻辑（时空—语义融合链）

整个知识图谱体现出如下**五层逻辑路径**：

```
本体层（主题）
    ↓
实体层（生态要素）
    ↓
指标层（遥感量化）
    ↓
时空层（时间尺度 + 空间区域 + 图斑）
    ↓
语义层（恢复阶段）
```

### 详细层级说明

#### 1. 本体层（主题）
- **节点**：震后滑坡生态恢复
- **作用**：定义整个知识图谱的主题领域

#### 2. 实体层（生态要素）
- **节点**：滑坡 → 植被、土壤
- **作用**：表征具体的生态要素及其层次关系

#### 3. 指标层（遥感量化）
- **节点**：NDVI、NBR、滑坡面积
- **作用**：提供遥感监测的量化指标

#### 4. 时空层（时间尺度 + 空间区域 + 图斑）
- **时间尺度**：宏观/中观/微观
- **空间区域**：九寨沟滑坡区
- **图斑**：Sentinel-2 图斑
- **作用**：提供时空维度的分析框架

#### 5. 语义层（恢复阶段）
- **节点**：发生前 → 发生后 → 恢复中 → 已恢复
- **作用**：描述生态系统的演化过程和恢复阶段

### 整合机制

最终通过**监测场景节点**将这些要素整合成"多时间尺度下滑坡生态恢复的语义监测网络"。

监测场景节点作为核心整合点，连接：
- 监测对象（实体）
- 监测区域（空间区域）
- 监测尺度（时间尺度）
- 分析指标（指数）
- 反映状态（状态）

## 📊 知识图谱设计理念

### 核心目标

构建一个**多尺度、多指标、多时相**的"震后滑坡生态恢复知识图谱"，实现：

1. **节点表达**：用节点表达地物对象、生态指标、时空尺度
2. **关系串联**：用关系串起演化逻辑与语义推理
3. **知识转化**：实现从"数据"到"知识"的结构化表达

### 设计特点

- ✅ **层次清晰**：从本体到具体图斑，层次分明
- ✅ **关系丰富**：多种关系类型支持复杂的知识推理
- ✅ **时空融合**：时间尺度和空间区域有机结合
- ✅ **语义驱动**：通过语义层实现知识推理和解释
