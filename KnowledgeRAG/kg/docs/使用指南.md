## 📖 概述

这是一个完整的知识图谱 Agent 系统,能够:

## 🚀 快速开始

### 1. 基础使用

```python
from kg_agent_enhanced import EnhancedKnowledgeGraphAgent
from neo4j_tools import Neo4jTools

# 配置连接
URI = "bolt://127.0.0.1:8687"
USER = "neo4j"
PASSWORD = "your_password"

# 创建 Agent
with Neo4jTools(URI, USER, PASSWORD) as neo4j_tools:
    agent = EnhancedKnowledgeGraphAgent(neo4j_tools)
    
    # 简单查询 - 返回自然语言
    response = agent.query_with_context(
        "有哪些指数可以使用?",
        tool_calls=[{
            "tool": "get_nodes_by_label",
            "parameters": {"label": "指数"}
        }]
    )
    print(response)
```

```

3. **NBR** (指数)
   - 含义: 扰动及火烧强度
4. **地表反照率** (指数)
   - 含义: 能量反射特性
5. **土壤湿度** (指数)
   - 含义: 地表含水状态
```

```python
response = agent.query_with_context(
    "植被和土壤分别用什么指数监测?",
    tool_calls=[{
```

## 🎯 实际应用场景

### 场景 1: 查询图斑的 NDVI 和 NDWI 指数

如果您的知识图谱中有图斑数据,可以这样查询:

```python
response = agent.query_with_context(
    "图斑A的NDVI和NDWI指数是多少?属于什么阶段?",
    tool_calls=[{
        "tool": "execute_cypher",
        "parameters": {
            "query": """
                MATCH (patch:图斑 {名称: '图斑A'})
                OPTIONAL MATCH (patch)-[:观测指数]->(ndvi:指数 {名称: 'NDVI'})
                OPTIONAL MATCH (patch)-[:观测指数]->(ndwi:指数 {名称: 'NDWI'})
                OPTIONAL MATCH (patch)-[:对应阶段]->(phase:状态)
                RETURN patch.名称 AS 图斑,
                       ndvi.名称 AS NDVI指数,
                       ndvi.含义 AS NDVI含义,
                       ndwi.名称 AS NDWI指数,
                       ndwi.含义 AS NDWI含义,
                       collect(DISTINCT phase.名称) AS 所属阶段
            """
        }
    }]
)
```

### 场景 2: 查询某月的图斑数据

如果图斑有时间序列观测值:

```python
response = agent.query_with_context(
    "2024年3月图斑A的NDVI和NDWI是多少?",
    tool_calls=[{
        "tool": "execute_cypher",
        "parameters": {
            "query": """
                MATCH (patch:图斑 {名称: '图斑A'})
                MATCH (patch)-[r:观测数据]->(obs:观测值)
                WHERE obs.月份 = '2024-03' 
                  AND obs.指数 IN ['NDVI', 'NDWI']
                RETURN patch.名称 AS 图斑,
                       obs.指数 AS 指数名称,
                       obs.值 AS 指数值,
                       obs.月份 AS 时间,
                       obs.阶段 AS 所属阶段
                ORDER BY obs.指数
            """,
            "parameters": {}
        }
    }]
)
```

## 🛠️ 可用工具列表

| 工具名称 | 功能 | 参数 |
|---------|------|------|
| `get_all_nodes` | 获取所有节点 | `limit` |
| `get_nodes_by_label` | 按标签获取节点 | `label`, `limit` |
| `get_all_relationships` | 获取所有关系 | `limit` |
| `get_node_by_property` | 按属性查找节点 | `label`, `property_name`, `property_value` |
| `get_node_relationships` | 获取节点的关系 | `node_label`, `node_property`, `node_value`, `direction` |
| `find_path` | 查找两节点间路径 | `start_*`, `end_*`, `max_depth` |
| `get_schema_info` | 获取图谱结构 | 无 |
| `execute_cypher` | 执行自定义查询 | `query`, `parameters` |

## 🔧 与 LLM 集成

### 集成 OpenAI/Claude 等大模型

```python
import openai

def chat_with_kg_agent(user_input, agent):
    # 1. 获取工具描述
    tools = agent.get_tool_descriptions()
    
    # 2. 让 LLM 理解用户意图并选择工具
    response = openai.ChatCompletion.create(
        model="gpt-4",
        messages=[
            {"role": "system", "content": f"你是知识图谱助手,可用工具: {tools}"},
            {"role": "user", "content": user_input}
        ],
        functions=tools,
        function_call="auto"
    )
    
    # 3. 提取工具调用
    if response.choices[0].get("function_call"):
        tool_calls = [
            {
                "tool": response.choices[0]["function_call"]["name"],
                "parameters": json.loads(response.choices[0]["function_call"]["arguments"])
            }
        ]
        
        # 4. 执行查询
        result = agent.query_with_context(user_input, tool_calls=tool_calls)
        return result
    else:
        return "无法理解查询意图"

# 使用示例
response = chat_with_kg_agent("植被用什么指数监测?", agent)
print(response)
```

## 🐛 常见问题

### 1. JSON 序列化错误

**问题:** `TypeError: Object of type Date is not JSON serializable`

**解决:** 已在代码中添加 `convert_neo4j_types` 函数自动处理

### 2. 节点属性名称问题

**问题:** 警告 `property name does not exist`

**解决:** 使用 `名称` 而不是 `name` 作为属性名

### 3. Neo4j 版本兼容

**问题:** `ID()` 函数已弃用

**解决:** 使用 `elementId()` (Neo4j 5.x+) 或 `ID()` (旧版本)
