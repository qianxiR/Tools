# 哨兵影像波段值提取与预处理系统

## 功能概述

本系统用于从Google Earth Engine提取Sentinel-2卫星影像的波段值，并进行数据预处理。支持批量处理多个数据文件。

### 主要特性

- ✅ **多格式支持**：支持CSV、XLS、XLSX格式的输入文件
- ✅ **批量处理**：自动遍历文件夹中的所有数据文件
- ✅ **自动坐标转换**：CGCS2000 → WGS84
- ✅ **波段值提取**：提取Sentinel-2的B2-B12共11个波段
- ✅ **地表反射率转换**：自动缩放波段值（×0.0001）
- ✅ **数据预处理**：缺失值填充、异常值裁剪、数据清洗
- ✅ **可视化分析**：生成相关性热图和数据分析报告

## 使用指南

### 1. 配置参数

编辑 `config.py` 文件：

```python
# 输入数据文件夹（放置CSV/XLS/XLSX文件）
INPUT_FOLDER = r'E:\1代码\模型\gee\数据'

# 时间范围
START_DATE = '2025-06-01'
END_DATE = '2025-07-31'

# 云覆盖阈值
CLOUD_THRESHOLD = 30  # 百分比

# 批次大小（每批处理的点数）
BATCH_SIZE = 500
```

### 2. 准备输入数据

将数据文件放入 `INPUT_FOLDER` 指定的文件夹中。

**输入文件格式要求：**
- 支持格式：`.csv`、`.xls`、`.xlsx`
- 必需列：
  - `N`：CGCS2000投影坐标的北向坐标
  - `E`：CGCS2000投影坐标的东向坐标
  - `水深`：水深值（可选，可为空）

**示例数据格式：**

| N | E | 水深 |
|---|---|------|
| 3700000 | 500000 | 2.5 |
| 3700100 | 500100 | 3.2 |

### 3. 运行波段值提取

```bash
python extract_sentinel_band_values.py
```

**功能说明：**
- 自动扫描输入文件夹中的所有表格文件
- 遍历处理每个文件
- 为每个文件生成独立的临时批次文件
- 输出格式：`{文件名}_temp_batch{批次号}.csv`

**输出示例：**
```
湖库合并结果_temp_batch1.csv
湖库合并结果_temp_batch2.csv
另一个数据_temp_batch1.csv
```

### 4. 运行数据合并与预处理

```bash
python merge_and_preprocess.py
```

**功能说明：**
- 自动查找所有临时批次文件（支持CSV/XLS/XLSX）
- 合并去重
- 数据预处理
- 生成多个版本的输出文件

**输出文件：**

1. **湖库波段值_合并完整.csv**
   - 原始波段DN值
   - 所有批次合并后的完整数据

2. **湖库波段值_缩放后.csv** ⭐ 新增
   - 波段值已缩放为地表反射率（×0.0001）
   - 适合直接用于分析

3. **湖库波段值_预处理后.csv**
   - 缩放 + 缺失值填充 + 异常值裁剪
   - 适合机器学习建模

4. **数据分析报告.txt**
   - 数据质量统计
   - 缺失值分析
   - 异常值检测

5. **波段相关性热图.png**
   - 波段之间的相关性可视化

### 5. 使用流水线脚本（可选）

如果想一次运行完整流程：

```bash
python run_pipeline.py
```

## 数据预处理流程

### 预处理步骤

1. **波段值缩放**（×0.0001）
   - 将DN值转换为地表反射率

2. **移除无效样本**
   - 删除所有波段都为NaN的记录

3. **缺失值填充**
   - 使用中位数填充缺失的波段值

4. **异常值裁剪**
   - 使用99.5%和0.5%分位数裁剪极端值

5. **数据类型优化**
   - 转换为float32节省内存

## 常见问题

### Q1: 如何处理不同投影坐标系的数据？

A: 当前系统使用EPSG:4549（CGCS2000 3度分带CM 96E）。如需其他投影，请修改：

```python
# extract_sentinel_band_values.py 第61行
transformer = Transformer.from_crs("EPSG:4549", "EPSG:4326", always_xy=True)
```

### Q2: 为什么有些点提取失败？

A: 可能原因：
- 该位置没有符合时间范围和云量阈值的影像
- 坐标超出Sentinel-2覆盖范围
- GEE API访问超时

### Q3: 如何调整批次大小？

A: 在 `config.py` 中修改 `BATCH_SIZE` 参数。建议值：
- 网络良好：500-1000
- 网络较差：100-300
- GEE配额受限：50-100

### Q4: Excel文件读取失败怎么办？

A: 确保已安装所需的库：

```bash
# 对于.xlsx文件
pip install openpyxl

# 对于.xls文件
pip install xlrd
```

### Q5: 如何跳过某些文件？

A: 系统会自动跳过包含以下关键词的文件：
- `波段值`
- `temp_batch`
- `合并`
- `预处理`
- `缩放`

如需自定义，请修改 `extract_sentinel_band_values.py` 第280行。

## 性能优化建议

1. **批量处理**：一次性放入多个小文件比分次处理更高效
2. **批次大小**：根据网络状况调整BATCH_SIZE
3. **时间范围**：缩小时间范围可提高影像质量
4. **云量阈值**：降低CLOUD_THRESHOLD可获得更清晰的影像
